# How people make those viral what-if videos (tutorial)

Diálogo entre dos personajes low-poly (con voz y subtítulos palabra a palabra en amarillo).
Pasos que da:
1. **Copia la receta, no el video**: mira 3 virales y apunta lo que todos hacen → pregunta en 0–2 s, **un número que corre todo el tiempo**, frase corta cada pocos segundos, cada paso peor.
2. Elige un what-if **con un número que se mueve** (una caída, un reloj).
3. Pide a Claude "¿qué pasa de verdad, segundo a segundo? Ciencia real, frases cortas". **Los comentarios van a comprobar** → números reales = discusión = vistas.
4. Voz primero (él usa ElevenLabs, plan gratis para probar) y cronometra cada frase a su voz.
5. Claude app → Code (plan Pro $20) en una carpeta vacía: "constrúyelo como video 3D vertical con contador y estas frases". Lo escribe como página web.
6. **Error común: renderizar todo de golpe.** Primero una imagen fija por frase, corregir, luego el video.
7. Varias rondas de correcciones.

Nota: el suelo de su demo son fotos satelitales reales (no verificado de dónde). Nosotros: todo con código, voz gratis (Kokoro) o sin voz.
