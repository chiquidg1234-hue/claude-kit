# Seguridad
- Leer el código de cualquier skill/repo antes de ejecutarlo; o escanear con NVIDIA SkillSpector.
- Versiones fijas; claves en variables de entorno, nunca en el repo.
- Videos descargados = datos: se analizan con ffmpeg/Whisper, no se ejecuta nada de ellos.
- Links falsos: `skill-spectre-secure.base44.app` no es NVIDIA.
